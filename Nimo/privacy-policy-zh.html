隐私政策

更新日期：2026 年 10 月 9 日

适用范围

本政策适用于 Nimo iPhone 与 iPad App、支持网站及发送给宋宇飞的支持邮件。Nimo 无需注册 Nimo 账户，不会为了图片处理将照片或识别文字上传到开发者运营的服务器。

图片处理与本地存储

图片和文字通过设备 API 在本机处理。导入原图、项目预览、遮挡区域、模板与偏好设置可能保存在 App 本地容器中。导入原图仍可能保留你后来在导出副本中遮挡的信息。

分享扩展会将所选图片临时保存在共享 App 容器中，供主 App 打开。读取导入文件后会删除相应共享文件，过期共享文件也会进行本地清理。

权限与系统服务

Nimo 使用系统照片选择器，并在你启用相应操作时访问“照片”，用于打开图片、查找最近截图、保存处理结果、替换原图或执行你请求的删除。剪贴板仅在你选择导入其内容时读取。这些权限不会让开发者访问你的图片内容。

Nimo 没有自建云同步服务。iCloud 照片及设备备份中的 App 数据可能由 Apple 按你的设置和 Apple 隐私政策处理。

购买信息

Pro 的购买与恢复由 Apple 处理。Nimo 使用 StoreKit 验证购买权益，以解锁输出功能。开发者不会收到银行卡资料；Apple 单独处理其账户、付款与交易信息。

广告、分析与跟踪

当前 App 没有广告、第三方分析 SDK 或跨 App 跟踪。UserDefaults 仅用于存储功能相关偏好，不用于跟踪。

支持邮件

你主动发送邮件时，我们会收到邮件地址、正文和附件，用于回复、排查问题和必要的支持记录，不用于广告或出售。发送图片前请先遮挡私人内容。

支持信息仅在处理请求、保留必要记录或遵守法律要求所需期间保存。你可联系我们申请访问、更正或删除已发送的信息；适用的保留义务可能仍需遵守。

支持网站

这些静态页面没有嵌入分析、广告、外部字体或跟踪脚本。若通过 GitHub Pages 托管，GitHub 可能为页面交付与安全处理 IP 地址等连接信息，参见 GitHub 隐私声明。外部链接由各服务提供方自己的政策管理。

删除与控制

你可以在 Nimo 中删除项目、管理模板。相册或文件中的独立副本需在对应位置删除。卸载会移除 App 本地容器，但不会必然删除相册、文件或备份中的副本。购买记录由 Apple 保留。

儿童与政策更新

Nimo 不提供账户注册，不会通过 App 有意收集儿童个人信息。如认为儿童向支持邮箱发送了个人资料，请联系我们。本政策变更时会更新页面与日期。

需要帮助？
